# Авторы и источники

## Код

Основа — **hi-Kernel 0.1.0** (ваш код): GDT, IDT, PIC, менеджер физической
памяти, клавиатура, первый шелл. В hix он сохранён и вынесен по слоям:
`arch/x86`, `aether/pmm.c`, `drivers/`, `qubix/shell.c`. Всё остальное
(планировщик, порты, процессы, VFS, steel, desk, игры, шахматы) написано поверх.

## Шрифты и глифы

- **DejaVu Sans / Sans Mono / Sans Bold** — гладкие шрифты пиксельного режима
  (лицензия Bitstream Vera / DejaVu, свободное распространение).
- **GNU FreeSerif** — глифы шахматных фигур (GPL с исключением для шрифтов).

Растеризованные данные лежат в `steel/gfx_data.c`; он генерируется
`scripts/genfont.py` и правится только через него.

## Иконки и обои

Иконки программ нарисованы с нуля скриптом `scripts/genicons.py`, обои и
тема Argent — `steel/theme.cpp`; сторонних изображений нет.
