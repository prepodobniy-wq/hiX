# Authors and sources

## Code

The foundation is **hi-Kernel 0.1.0** (your code): GDT, IDT, PIC, the physical
memory manager, the keyboard, and the first shell. In hix it is preserved and
split into layers: `arch/x86`, `aether/pmm.c`, `drivers/`, `qubix/shell.c`.
Everything else (scheduler, ports, processes, VFS, steel, desk, games, chess)
was written on top.

## Fonts and glyphs

- **DejaVu Sans / Sans Mono / Sans Bold** — smooth fonts for the pixel mode
  (Bitstream Vera / DejaVu license, freely redistributable).
- **GNU FreeSerif** — chess piece glyphs (GPL with a font exception).

The rasterized data lives in `steel/gfx_data.c`; it is generated by
`scripts/genfont.py` and should only be edited through it.

## Icons and wallpaper

The application icons were drawn from scratch by `scripts/genicons.py`; the
wallpaper and starry wallpaper, panels and the Argent theme are in
`steel/theme.cpp`, `steel/panel.cpp`; there are no third-party images.

## Cryptography

- **ChaCha20-Poly1305** is implemented in `rust/hix-core` according to RFC 8439;
  there are no third-party crypto libraries.
- The **Rust core** for i686 comes from the standard toolchain (MIT/Apache-2.0;
  used under MIT) and is linked as `no_std`.
