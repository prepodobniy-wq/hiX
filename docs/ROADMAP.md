# План

Каждый этап проверяется хост-тестами и кадрами `make shots`; загрузка в QEMU
проверяется отдельно (`make smoke`, а для релиза — `make release`), поэтому
после каждого выпуска всё равно нужна ваша проверка на своём железе.

## 0.4.0 — сделано
Gantry (реестр, драйверы), буфер кадра в ОЗУ, перетаскивание спрайтом.

## 0.5.0 — кольцо 3 (этап 1 сделан: адресные пространства, ELF, int 0x80, hello3/fault3/probe3; дальше — libc-обвязка, fork/exec-подобный запуск, перенос программ)
- отдельные адресные пространства (страничные каталоги на процесс, TSS.esp0);
- загрузчик ELF, пользовательские программы через `int 0x80`;
- переезд qubix-программ (shell, tasks, ...) в ring 3 по одной;
- проверка указателей из пользовательской памяти вместо `user_ok` на «своём» адресе.

## 0.6.0 (сделано частично: Kit, сервисы, SDK, /bin; осталось графическое приложение) — Kit (SDK)
- библиотека для пользовательских программ: окно, виджеты, события, пиксельный холст;
- первое графическое приложение, написанное на Kit, вне ядра.

## 0.6.1 — сделано: Rust в ядре и проверка шифра
- необязательный `no_std`-модуль `rust/hix-core` (ChaCha20-Poly1305), C ABI,
  `SYS_crypto` (601), `hx_crypto()` в SDK, `cryptotest`;
- Python-эталон `scripts/crypto_check.py` (`make crypto-test`) и self-test при
  загрузке; без i686-core ядро собирается, вызов возвращает `-ENOSYS`;
- дальше: заменить пример на шифр соседней команды и при необходимости вынести
  интерпретатор Python в ring 3 (MicroPython), а не в ring 0.

## 1.0.0 — сделано: стабильный публичный выпуск
- загрузочный опыт: splash, quiet VGA, четыре скринсейвера, автозапуск по
  простою, сохранение недопечатанной строки; настройка `config/hix.conf` →
  `build/hixconfig.h` через `scripts/hixctl`;
- runtime-параметры `hix.splash`, `hix.quiet`, `hix.screensaver`,
  `hix.timeout`, `hix.safe`; sysctl `hix.boot` и `kern.cmdline`;
- GRUB-меню с обычным, verbose, no-splash, safe и serial-входом; COM1 —
  полноценный шелл;
- одна версия в `include/hix/version.h`; `make version`, `verify`, `smoke`,
  `release`; чистый strict-билд с Rust и ISO, QEMU smoke, `dist/` с
  `SHA256SUMS`, `BUILD-INFO` и исходниками;
- исправлены `GANTRY_LOOKUP`, `%-12s` в `hx_printf`, гонки smoke-теста;
- добавлены LICENSE, INSTALL/RELEASE/VERSIONING, CONTRIBUTING, SECURITY,
  release notes и CI;
- проверено: strict-сборка, `make verify`, `smoke --require-rust`; text
  около 218 КиБ с Rust.
